# Basic Mathematical Calculator

  This project is a simple math calculator, this calculator can perform the basic addition, subtraction, multiplication, division. This Project is created within C++. This calculator can also handle mathematical computations with very large numbers. The user can choose the operation and input multiple numbers to calculate the result and the program continues to run until the user decides to exit.
